### 3. 宏御 🟡

**数据源**：内联 `CALC_DATA_INLINE`（1599键，936KB），结构 `{E: 基本保额, y: [[J, M100, O, P], ...]}`

**口径**：每千元保费，scale = premium / 1000

**计算逻辑**（递归公式）：

```
第1年: K = round(M * scale * 10000 / O)
第2年+: K = round((M * scale * 10000 + cumK * prevO * 0.01225) / O)
N(交清增额现价) = round(cumK * P / 10000)
G(保证现金价值) = J * scale
生存总利益 = G + N
```

**问题**：

1. 🟡 **0.01225常量**：递归公式中的0.01225（1.225%）是累积交清增额的利息因子，需与官方Excel核对是否一致。若无官方Excel验证，标记为待确认。
2. 🟡 **canvas导出独立重算**：`downloadImage()`中使用独立的 `dlCumK/dlPrevO/dlPrevTotal` 变量重新计算全部数据，而非直接读取DOM。两条计算路径若维护不同步会导致导出图与页面不一致。当前两套代码逻辑相同，暂未发现差异。

**精度**：内联数据全为整数，Math.round取整。与官方表一致（官方表也为整元）。

**导出一致性**：自定义canvas绘制 + html2canvas双通道。canvas路径重算数据。⚠

**硬编码**：无 ✓

### 5. 宏泰 🔴 已确认存在数据错误

**数据源**：内联 `HONGTAI_DATA` 数组，**仅56行硬编码数据**（49岁/女/3年交/50万保费）

**核心问题**：

页面允许用户输入年龄（0-73岁）、性别（男/女）、交费期间，但底层数据**只有一组**：

```javascript
// HONGTAI_DATA 第1行：49岁，500000保费
{yr: 1, age: 49, prem: 500000, exempt: 1998750, guar_amt: 700000, ...}
```

generate() 函数的处理方式：

- `sumAssured = Math.round(1332500 * (premium/500000))` — 仅按保费缩放
- `scale = premium / 500000` — 所有数值按保费比例缩放
- HTML表格年龄列：使用 `age + yr`（用户输入年龄+年数）— **年龄列正确**
- **所有金额数值**：直接取HONGTAI_DATA按scale缩放 — **数值错误**

**具体影响**：

| 用户输入           | 年龄列         | 金额数值    | 正确性     |
| -------------- | ----------- | ------- | ------- |
| 49岁/女/3年交/50万  | 49,50,51... | 基准数据    | ✓ 正确    |
| 30岁/女/3年交/100万 | 30,31,32... | 49岁数据×2 | ✗ 数值错误  |
| 49岁/男/3年交/50万  | 49,50,51... | 女性数据    | ✗ 性别错误  |
| 49岁/女/5年交/50万  | 49,50,51... | 3年交数据   | ✗ 交费期错误 |

**根因**：宏泰演算器缺少完整的利益演示数据表，仅用单案例数据+保费缩放替代。不同年龄/性别/交费期的保险利益差异无法通过简单缩放体现。

**修复所需**：需要宏泰产品各年龄/性别/交费期间的完整利益演示数据表（类似盈满鑫的JSON结构），或确认该产品是否只支持单一投保场景。

**导出一致性**：canvas导出使用 `r.age`（硬编码年龄），与HTML表格的 `age+yr` 不一致。⚠

### 9. 华彩 🟡

**数据源**：内联 `HC_DATA` 数组 + `HC_BASE = {age: 35, term: 3, prem: 100000}`

**口径**：scale = premium / HC_BASE.prem，ageOffset = age - HC_BASE.age

**字段映射**：currPrem→当年保费, cumPrem→累计保费, aAnn→年金, cAnn→累计年金, maturity→满期金, death→身故, cv→现金价值, cumDiv→累计红利, survDiv→生存总利益。✓

**问题**：

1. 🟡 **单一基准案例**：HC_DATA 为35岁/3年交/10万保费的基准数据。代码通过 `ageOffset` 调整年龄列显示，通过 `scale` 缩放保费，但**所有金额数值（cv/death/maturity等）仍为35岁基准数据按保费缩放**。若产品利益随年龄变化（保险产品通常如此），则非35岁输入的金额数值不准确。
2. 🟡 **交费期间固定**：HC_BASE.term = 3，数据中的保费列仅前3年有值。若页面允许选择5年交/10年交，保费列和数据将不匹配。

**待确认**：需确认华彩产品是否支持多年龄/多交费期间输入。若仅支持单一场景则为设计限制而非错误；若支持多场景则需补充完整数据表。

**导出一致性**：canvas导出使用 `dlOff = age - HC_BASE.age` 调整年龄，与页面一致。✓
