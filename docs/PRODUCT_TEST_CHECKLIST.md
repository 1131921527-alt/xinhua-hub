# 新华Hub 产品测试清单（PRODUCT_TEST_CHECKLIST）

> **目的**：针对每个产品生成验收标准，供未来自动化测试逐款回归。
> **对应工具**：`tests/product-rule-check.js`（其 5 大项已映射为本清单的 10 个检查点）。
> **生成日期**：2026-07-30。本文只描述验收标准，**不修改代码**。

---

## 0. 通用验收清单（每款产品必检 10 项）

| 类别 | 检查项 | ✅ 标准 | 自动化断言点 |
|---|---|---|---|
| 页面 | 正常打开 | 无白屏、无致命 JS 报错 | Playwright 加载无 `pageerror` |
| 参数 | 年龄 | 可输入 / 选择有效年龄 | 表单字段存在且可赋值 |
| 参数 | 性别 | 可选 男 / 女 | 性别控件可切换 |
| 参数 | 交费方式 | 可选（如 3年交 / 5年交 / 趸交） | 交费方式控件可切换 |
| 计算 | 数据生成 | 点「生成」后表格有数据，行数符合预期 | `generate()` 后 `#planArea` 含 ≥1 行 |
| 展示 | 储备期 | 储备期行 / 列标记正确（按 `product-rules.js`） | 主表合并单元格 `rowspan` = 储备期年数 |
| 展示 | 收益率 | 储备期后正确展示，或显示「-」（`showRate=false`） | 储备期后首行含 `%` 或 `-` |
| 展示 | 表格布局 | 列对齐、无错位、响应式正常 | 桌面 / 手机截图无溢出 |
| 下载 | PNG 正常 | 点击下载生成 PNG，无报错 | 触发下载 / `window.__dlBlob` 非空 + PNG 签名 |
| 下载 | 图片完整 | PNG 含完整表格，与页面数据一致 | 截图与页面关键数值比对一致 |

## 1. 逐产品验收清单

> 标注说明：**适用** = 按标准检查；**不适用** = 该产品无此概念（如恒享无储备期）；**人工** = 需人工核对截图（DOM 无法断言）。

### 1.1 盈满鑫（yingmanxin，进规则层，payterm）
- 特殊点：**两种交费方式须分别测**（3年交 → 储备期3年；5年交 → 储备期5年）。
- 10 项全适用；储备期 = 交费期（动态判定）。

### 1.2 宏御世家（hongyu，进规则层，fixed 5）
- 全适用。储备期 5 年，展示收益率。
- 注意：主表用内联逻辑读 `RULE.reserveYears`（验收已知，非缺陷）。

### 1.3 宏安世家（hongan，进规则层，fixed 5）
- 全适用。储备期 5 年，展示收益率。

### 1.4 宏泰世家（hongtai，进规则层，fixed 5）
- 全适用。储备期 5 年，展示收益率。

### 1.5 宏愿人生（hongyuan，进规则层，fixed 5）
- 全适用。储备期 5 年，展示收益率。

### 1.6 宏禧来（hongxilai，进规则层，dynamic `rate<=0`）
- 特殊点：储备期 = **收益率 ≤ 0 的那些年**（动态），非固定 5 年。
- 展示项：储备期后首行须含 `%`（展示收益率）。

### 1.7 华彩鎏金（huacai，进规则层，fixed 5，showRate=false）
- 特殊点：储备期 5 年，但**储备期后显示「-」而非收益率**。
- 展示-收益率项：断言为「-」。

### 1.8 宏坤人生（hongkun，进规则层，fixed 5，showRate=false）
- 同华彩：储备期 5 年，储备期后显示「-」。

### 1.9 福盛世家（fusheng，不进规则层，本地 reserveYears=5）
- 页面 / 参数 / 计算 / 下载：全适用。
- **展示-储备期：人工**（主表无储备期列，仅下载 canvas 手绘前 5 年标记，需人工核对截图）。
- 展示-收益率：不适用（无统一收益率展示）。

### 1.10 恒享人生（hengxiang，不参与储备期体系）
- 页面 / 参数 / 计算 / 下载：全适用。
- **展示-储备期：不适用**；**展示-收益率：不适用**（无储备期 / 收益率概念）。
