# 公司介绍：A4直接查看与打印

- 常用入口为「A4 查看 / 打印」，点击后直接生成并打开已验收的四页蓝金PDF，不必选择格式、模块或清晰度；正文原图片按钮同样改为A4入口。
- 一键入口始终导出全篇，即使之前在更多格式中选择过单个模块，也不会误导出局部内容。
- 使用同一正式数据与矢量PDF组件动态生成，没有另存一份可能过期的静态正文。浏览器PDF阅读器可打印、保存；未自动调用物理打印机。
- PNG、PPT及单模块输出仍放在「更多格式」；内容拼装器链接移到该菜单，功能未删除。
- 被拦截的新窗口可在原页直接查看或下载；字体资源缺失则明确报错，不生成假文件。
- 校对补全了「部分产品现金红利实现率」「分红年度」及118%适用范围的表述，未改变业务数值、红利公式或保险演算器。
- 本地验证390/430/1440一键打开、四页全篇、真实PDF下载、弹窗拦截回退与字体失败路径；同一正文PNG/PDF/PPT与单模块导出回归。手机物理设备与WorkBuddy独立QA未在本轮实测。
- 测试样本与截图放在项目外private-review，不进入公开仓库。
