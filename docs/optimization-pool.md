# 新华 Hub V5.0 优化任务池

> 定位：本项目长期维护的软件产品优化清单。每次自动/手动从此池选**最高优先级**任务执行。
> 目标：让优秀理财经理每天打开新华 Hub 能完成——产品查询 / 客户分析 / 方案制作 / 销售学习 / 问题解决 / 客户经营。
> 流程：发现问题 → 修改 → 本地测试(PC) → 手机测试 → 提交 GitHub → 汇报。
> 红线：不碰 V4.2 演算器 / PNG 导出 / 手机适配；不动收益公式与产品数据。

## 分类与优先级说明
- **分类**：`A` 必须修改（直接执行）｜`B` 建议优化（整理后执行）｜`C` 未来规划
- **优先级**：`P0` 产品逻辑/数据准确性 ＞ `P1` 首页与导航体验 ＞ `P2` 高频销售工具/内容建设 ＞ `P3` 内容合并/工作台/AI预留
- **状态**：`待办` / `进行中` / `已完成(完成日期)` / `待汇报`(涉及产品数据/收益计算/公式/重大销售逻辑，先汇报再动)
- **低风险可直接执行**；凡涉及产品数据、收益计算、公式、重大销售逻辑修改 → 状态置 `待汇报`，先向用户汇报。
