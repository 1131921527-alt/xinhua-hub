## 四、data_huacai.json 设计方案

**键格式**：`{gender}_{age}_{term}_{year}`（与官方主键一致）

**数值口径**：每千元保费。页面保费缩放改为 `scale = premium / 1000`，替换现有 `scale = premium / 100000`。

**字段集**（每条记录）：
```json
{
  "gender": 1, "age": 35, "term": 3, "year": 1,
  "prem": 1000, "cum_prem": 1000,
  "annuity": 0, "annuity_cum": 0, "maturity": 0,
  "death": 1000, "cv": 438.2,
  "guar_annual_div": 0, "guar_cum_div": 0,
  "div_annual": 11.29, "div_cum": 11.29
}
```

**覆盖率**（草案实测）：
- 性别：男 / 女 全覆盖
- 年龄：0 ~ 72 岁，共 73 个年龄点
- 交费期间：趸交 / 3 / 5 / 10 年
- 组合总数：562 个 (gender,age,term) 组合，39,524 条年度记录

## 五、方案选择

由于官方明确支持多维度，**采用方案 B（完整数据迁移）**，不再走「冻结输入」的妥协方案。

迁移要点：
1. 用 `data_huacai.draft.json` 替换内联 `HC_DATA`，键格式统一。
2. `generate()` 改为按 `{gender}_{age}_{term}_{year}` 查表，删除 `ageOffset` 只调列不调值的逻辑。
3. 分红方式（累积生息 / 交清增额）：当前全量表为累积生息口径；若需交清增额，需另取对应官方表或确认是否同一数据集。
4. 保险期间到 105 岁：全量表年龄覆盖到 72+，保单年度需确认是否延伸到 105 岁；当前 HC_DATA 只到 79 岁，迁移时应以官方全量表实际年度为准。
