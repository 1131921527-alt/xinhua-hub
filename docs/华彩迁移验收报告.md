## 二、数据来源与口径（关键发现）

- 数据源：`files/演算器/S24华彩鎏金年金保险（分红型）利益演示.xlsx` → 工作表「华彩鎏金年金保险（分红型）利益演示全表」（39,524 条，主键 `{gender}_{age}_{term}_{year}`）。
- **重大发现（分红列口径）**：该全表的「保证利益演示」「红利利益演示」列中，**年度红利(col16)、累计红利(col17) 有值，但「累积红利(col18/col24，即按累积生息复利）显示为「按计算规则计算」占位**。经核对主演示 sheet（单案例权威数据），华彩的「累积红利」是按约 **1.76%**（非页面默认 2.5%）复利累积的演示值，且全表 col24 即直接给出该权威累积红利（女35/3/10万：Y10 col24=346.71/千元 = 34,671/10万，与原 HC_DATA 完全一致）。
- 因此 `data_huacai.json` 的 `div_cum` 取自全表 **col24（演示累积红利）**，而非 col16（年度红利）或 col17（简单累计）——这是与原 HC_DATA 精确对齐的关键。
- **生存总利益 / 身故总利益公式**（经主演示 sheet 反推、Y1–Y15 全部精确吻合）：
  - `生存总利益 = 现金价值 + 累积红利 + 累计年金`
  - `身故总利益 = max(身故保险金, 现金价值 + 累计年金) + 累积红利`
- 字段映射：当年保费←prem、累计保费←cum_prem、关爱金年金←annuity、累计关爱金年金←annuity_cum、满期金←maturity、身故金←death、现金价值←cv、累积红利←div_cum。
