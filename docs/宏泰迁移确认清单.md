## 一、哪些字段是「计算字段」（官方为占位文本）

对草案逐字段扫描，以下 3 个字段 **100% 为「按计算规则计算」占位**，无数值：

| 字段 | 含义 | 占位比例 |
|---|---|---|
| `sa_death` | 身故或身体全残保险金（保证） | 100% |
| `guar_cum_div` | 保证利益演示-累积红利 | 100% |
| `div_cum` | 红利利益演示-累积红利 | 100% |

其余字段（prem / cum_prem / exempt_accident / cv / guar_annual_div / div_annual / paidup_net / paidup_cv）均为官方直接数值，可直接使用。

## 二、建议的计算公式来源（供确认，非自行猜测）

1. **`sa_death`（保证身故金）**
   - 来源：官方「未发生减保利益演示」示例表（女49/3年交/50万）中该列有完整数值。
   - 规律：= max(累计保费 × 身故给付比例, 现金价值)，比例随投保年龄分段（与盈满鑫 `deathRatio` 思路一致）。
   - 需用官方示例表的数值反推各年龄段比例，或直接从条款取给付比例表。

2. **`guar_cum_div`（保证累积红利）**
   - 宏泰为保证利益演示，年度红利列（`guar_annual_div`）大部分为 0，累积红利通常也为 0。
   - 需确认：保证利益演示下累积红利是否恒为 0，还是按某利率累积。

3. **`div_cum`（红利累积红利）**
   - 来源：与现有代码中的 `currentRate` 复利逻辑一致，即 `div_cum = div_cum_prev×(1+rate) + div_annual`。
   - 需确认官方使用的累积利率（现有代码 rate 值）。
