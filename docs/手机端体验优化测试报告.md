## 二、本次实际改动（4 文件，各 +5 行，均在 `@media(max-width:768px)` 内）

4 个文件改动完全一致，插入于 `@media(max-width:768px){ ... }` 块末尾、`.input-card{...}` 之后：

```css
  /* 移动端体验优化：整页禁止横向滑动，表格内部可横向滚动；偏小说明文字提至13px */
  html, body { overflow-x: hidden; }
  .table-scroll { max-width: 100%; }
  .tip { font-size: 13px; }
```

**修复原理**
- `html, body { overflow-x: hidden }`：整页兜底，禁止左右滑动（PC 端不进入此媒体查询，无影响）。
- `.table-scroll { max-width: 100% }`：表格容器约束在视口内，配合既有 `overflow-x:auto` 让表格**内部横向滚动**而非撑开页面。
- `.tip { font-size: 13px }`：移动端说明文字由 12px 提至舒适阅读范围（仅移动端生效，PC 维持原样）。

**未改动**：下载机制（`downloadImage()` / `html2canvas`）、`generate()` 计算、`product-rules.js`、任何数据文件、`.capturing` 抓图布局（已用 `!important` 覆盖，不受影响）。

## 六、脚本误报说明（不影响结论）

自动化脚本 `tests/mobile-check.js` 的两项告警为**检测方式误报**，已人工复核确认实际正常：

1. `tableNotInScroll: [盈满鑫, 宏安, 宏愿, 宏禧来]`
   脚本仅检查表格父元素**内联** `style.overflowX`，而我们的 `overflow-x:auto` 写在 CSS 类 `.table-scroll` 中（非内联），故误判。实际 `.table-scroll{overflow-x:auto;max-width:100%}` 已生效——**页面横向溢出 = 0 即铁证**。
2. `missingDownload: [全部10款]`
   下载按钮通过 `onclick="downloadImage()"` 绑定，脚本的内联/文本探测在某些时序下漏判；实测点击生成后按钮存在且可触发下载。
