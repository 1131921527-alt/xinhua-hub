四、销售使用体验检查

P0 微信内置浏览器会拦截 github.io（未备案境外域名）
销售在微信里转发链接给客户，客户点开可能被拦截。这是「转发给客户」场景的最大风险。对策方向：核心页面考虑备案域名或引导「复制链接到浏览器打开」话术。
P0 4 款演算器在首页无入口：福盛世家 / 宏坤 / 宏泰 / 华彩
首页「产品测算」分类只挂 6 款（宏安/宏御/宏愿/盈满鑫/宏禧来/恒享）。福盛、宏坤、华彩全站零引用；宏泰仅出现在销售问答页提及。4 个文件已 git 跟踪、线上存在，但销售找不到。需确认：是未验收暂不展示，还是漏挂？
P1 2 款演算器数据加载慢：宏愿 6.5MB / 宏安 4.7MB
数据为懒加载（点测算才 fetch），页面打开快；但客户首次点测算在手机网络上需等待数秒。盈满鑫 680KB、宏禧来 345KB 属正常。对策方向：数据按需分片 / 提示加载中动画。
PASS 首页路径合理：销售找产品测算 2 步可达
首页 76KB、1 个 CSS + 1 个 JS、无图片，加载极快。15 个分类 58 个条目，「产品测算」排第 2 位，入口清晰。
PASS 导出图适合客户转发
导出图 1600-2000px 宽、保留核心指标卡（满期收益/累计收益/年化单利），微信缩略图可见关键数据。
P2 无 404 页面
链接打错时浏览器显示空白/默认错误，建议补一个带导航的 404.html。

六、版本管理机制（已建立）

基于现有 docs/CHANGELOG.md（已含 版本/日期/内容/原因/验证/commit 六要素），新增自动化工具 tools/version_log.py：

命令作用
python tools/version_log.py add "描述" --task T108 --verify "PC+手机 PASS"commit 后自动生成版本条目，提取日期/commit/影响文件/当天截图
python tools/version_log.py query --file calculator-hongan.html回答「这个页面什么时候改的、为什么改」
python tools/version_log.py query --since 2026-08-01查看某时间段的全部提交
python tools/version_log.py status查看待提交改动
python tools/version_log.py log查看最近版本记录

以后每次改动流程：开发 → 验收 → commit → 运行 add 自动记一笔。半年后随时能查「某页面为什么改」。
