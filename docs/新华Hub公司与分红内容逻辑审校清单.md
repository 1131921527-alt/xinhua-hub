# 新华Hub 公司与分红内容逻辑审校清单

## A 已确认可用

- 新华保险1996年成立、A+H上市、国有控股等基础信息，可沿用项目现有公司介绍与正式披露。
- 红利实现率用于比较实际红利与计划书演示红利，118%不等于收益率118%。
- 公司投资收益率是资产端经营指标，不等于客户保单红利收益率。
- 盈满鑫应同时区分合同保证利益、非保证分红和保险期间。

## B 表达需要更严谨

- “中投直管”应说明为管理关系或党组织关系口径，不写成国家对产品兜底。
- “主权基金”只能用于解释中投公司的机构定位，不能延伸为产品安全或收益保证。
- “分红账户”应表达为分红业务经营和可分配盈余口径，避免写成一个可以直接看到收益的“大账户”。

## C 需要更新的数据

- 公司经营数字：总资产、原保险保费收入、归母净利润、总投资收益率、综合投资收益率，应以最新年报/公告替换旧培训资料中的季度数字。
- 银行定期存款和大额存单利率具有时效性，本轮页面暂不写死具体数字。

## D 暂不写入的内容

- 盈满鑫身故保障的年龄边界和1.2/1.4/1.6倍比例，必须逐项对照正式条款和当前演算器规则后再展示。
- 无法逐项核实来源的历史产品红利实现率，不作为客户版核心数据。

## E 必须删除或避免

- “国家兜底”“保证分红”“保本保息”“稳赚”“一定比存款高”等收益或安全承诺。
- 把公司投资收益率直接换算成客户红利收益率。
- 把历史红利实现率、2025年度披露和产品演示收益混在同一张表中。
