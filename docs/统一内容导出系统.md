## PDF：忠实正文与矢量输出

公司介绍保留封面、身份、股东、经营、投资、分红机制、产品实现率、原始资料8个内容块，包含指标解释、历史指标、投资案例、配置条形图、时间线及关系图。导出前后按模块核对全部文本节点与重复次数、来源链接及图表签名；发现遗漏、溢出或未知字形即停止，不假成功。

公司介绍PDF直接绘制文字、边框、数据条和SVG，不将网页整页截图塞进PDF。嵌入HubExportSans正常/粗体中文子集和ToUnicode映射；正文可选中、搜索，关系图与线条可放大。手机版宽108mm，单页高度随内容；A4版为210×297mm，独立分页。渐变背景使用同色系矢量纯色，避免细条拼色产生接缝。

所有PDF正文取消自动页脚、日期、页码、长网址和重复通用免责声明；不是改小或移位。原正文的关键条件、报告期和风险解释仍在对应模块，来源原文集中末尾，不删必要信息。

## 高清PNG与视觉PPTX

- PNG设计宽750px，2倍输出1500px，公司介绍3倍输出2250px。使用安全分段、连续编号与真实ZIP，单画布不超过约900万像素，顺序渲染后释放内存；不静默降倍数冒充高清。
- 等待字体、图片、样式和图表就绪；失败时明确报错。SVG导出PNG/PPT前按完整viewBox独立渲染，并嵌入同款字体，避免html2canvas截掉右侧分支；PDF仍直接输出原SVG矢量。
- PPTX为真实OOXML、标准16:9，1280×720逻辑布局、2倍2560×1440图像。封面、偿付能力、历史指标、案例与来源页分别调整字号、卡片尺度和组合布局，不放大低清图冒充高清，不把长图塞进一页。
- 当前PPT是视觉型，正文非逐元素可编辑；备注保留对应原文。ZIP/OOXML及图像结构验证不等于PowerPoint/WPS实际打开验收。

## 入口、保存与兼容

正式内容页顶部提供显著“下载 / 导出”操作栏，滚动时保持可见；在正文流内预留空间，不遮挡图表、不占手机底部手势区。菜单提供实际支持的格式、生成状态、错误反馈和公司PNG清晰度。公司旧下载图片按钮转入同一套内容渲染。

提供真实下载文件、大小、预览与浏览器支持时的系统分享。微信/iOS限制环境给出查看、长按或浏览器打开指引；生成成功不等于保存到相册成功。隐藏导航和操作控件，保留必要来源/风险，范围选择继续可用。

## 字体与依赖

所有运行依赖同源加载，不依赖运行时外部CDN。复用html2canvas、jsPDF 4.2.1、PptxGenJS 4.0.1，新增svg2pdf.js 2.8.1（MIT）。HubExportSans从Google Fonts官方Noto Sans SC可变字体生成静态400/700子集并重命名，保留OFL许可、来源SHA256与字形覆盖表；仅扫描明确白名单内的正式公司内容。


内容新增未覆盖汉字时须重建字体并重跑验收，不能忽略字形错误。
