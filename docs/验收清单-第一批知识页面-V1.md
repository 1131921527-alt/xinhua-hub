## 共性问题与改进建议

### 共性问题

1. **页面间缺乏联动**——4 个页面各自独立，无交叉链接。实际业务场景中，客户投保（③）→ 获取保单（④）→ 答疑解惑（①）→ 数据说服（②）是一条完整链路，应建立导航串联。

2. **复制功能不统一**——仅 ④ 号页面有复制按钮，① 号页面话术最多但无复制功能，使用体验不一致。

3. **无统一搜索入口**——4 个页面均无搜索功能，理财经理跨页面查找信息只能靠目录锚点 + 滚动。

4. **真实性标注不统一**——① 号页面无 🟢🟡🔴 体系，其他 3 个页面有。建议统一标注标准。

5. **无更新日期机制**——部分页面有日期、部分无，数据型页面（②）需建立定期更新日历。
