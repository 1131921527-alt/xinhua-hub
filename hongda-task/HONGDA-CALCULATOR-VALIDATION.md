## 二、三项补充核验结论（开工前已写入 FIELD-MAPPING.md）

1. **S34 / S341 产品代码**：通篇公式 grep 命中 0；查表键 `AA11=性别_年龄_交费期`，**不含产品代码**；S34（非个养）与 S341（个养）共用同一利益表，仅经"是否个养"影响入口规则（年龄上限、保费上下限、个养年度缴费上限），不影响任何利益金额。⚠️ 风险边界：若监管要求 S341 单独利益表，源文件未提供，须记为 BLOCKED，不得造数。
2. **投保年龄校验（业务类型 × 交费期 双维度）**：非个养 趸75/3·5·6年70/10年65；个养女 75/52/50/49/45、个养男 75/57/55/54/50；个养另受"年龄+交费期≤退休年龄"硬约束。保费：非个养 趸≥3万·期≥1万且 1000 整数倍；个养 ≥500、100 整数倍、期交每年≤12000。
3. **对账逐年度逐字段**：12 组每组逐行比对 10 字段，差异必须为 0（见 §四、§五）。

> 顺带订正 FIELD-MAPPING 既有 3 处误差：①年龄显示=投保年龄+t（非 t−1）；②**身故金 K 用上一年累计年金**（Excel `C11=SIP!I+SIP!G(prev)+SIP!N`，前版误写"当年"已改正）；③满期金 积累期=0、末年=所交保费。

### 网页侧递归/合成项（原样复刻 Excel）
- 红利累积生息 `cumDiv = (t==1)? divYr : round(divYr + cumDivPrev×(1+K4))`，K4=0.0175。
- 保证累积红利 `guarCum = (t==1)? guarDivYr : round(guarDivYr + guarCumPrev×1.0175)`。
- **身故金** `deathTotal = deathBase + cumAnnuityPrev + cumDiv`（G 取上一年，与 Excel `C11` 一致）。
- **生存总利益** `survDiv = cvRaw + cumAnnuityUsed + cumDiv`；`cumAnnuityUsed = (t<Nyears)? cumAnnuity : cumAnnuityPrev`（末年取上一年，与 Excel `C12` 一致）。`survGuar` 同构改用 `guarCum`（页面新增保证口径，Excel 无对应列，属构造列）。
