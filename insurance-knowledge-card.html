1专有词汇 · 大白话解释

卖保险、看计划书，先搞懂这几个词，不然容易被"演示数字"带偏。

📌 目前利率水平（截至2025年9月调整后）

预定利率（写进合同的"成本价"）：

• 普通型：2.0%（2025.9起，从2.5%降）
• 分红型：预定利率上限 2.0%，但客户实际拿到的"保证复利"约 1.75%（如宏安世家"保底1.75%"）
• 万能型：保证利率上限 1.5%
👉 所以常说的"1.75%和2%"——2%是分红型预定利率，1.75%是客户实得保证复利，两者常被一起说成"预定利率水平"。

演示利率（计划书演算假设，非承诺）：分红险演示利率上限 = 3.5%。

预定利率

保险公司给产品定价时，承诺给客户的"内部回报率"。一旦写进合同就锁死不能变，是保险公司的刚性成本。

类比：产品的"出厂成本价"。成本越高，给客户的好处越多，但公司利差损风险也越大。

📌 记忆：预定利率 = 保险公司"承诺的回报率"，是底线，不是你到手的全部。

演示利率

分红险计划书上用来"演算"红利的假设利率，只是假设、不是承诺，且受监管上限约束。

类比：产品说明书里的"预期收益演算图"。画得好看，但不等于真能拿到。

📌 记忆：演示 ≠ 承诺。看计划书先看"保证利益"，再看"演示红利"。

分红实现率

实际派发的红利 ÷ 计划书演示的红利。反映"画的饼实际端上来几成"。100%即完全兑现，低于100%就是没达到演示。

类比：年初说发12个月奖金，年底只发9个月，实现率就是75%。

📌 记忆：实现率高 ≠ 你拿到手多（还得看预定利率高低）。看连续多年，别只看一年。

保证利益 / 保底

合同白纸黑字写死的部分（现金价值、固定返还），不管保险公司赚不赚，这一分都不少。

类比：工资里"固定底薪"。分红是"绩效奖金"，可多可少可为零。

📌 记忆：分红险 = 保底（确定）+ 分红（浮动）。先看保底够不够，再谈分红。

平滑机制

保险公司把投资好的年份多赚的钱存进"分红特别储备池"，差年份从池子里取水补分红，削峰填谷，让每年分红尽量平稳。

类比：丰年存粮、荒年放粮，年年有饭吃。

📌 记忆：平滑机制让分红"不会大起大落"，但池子也有耗尽的时候。

利差损

保险公司实际投资收益率 低于 保单预定利率，赚了保费却覆盖不了承诺成本，长期就亏钱。这是行业头号风险。

类比：你以5%利息借的钱，只能投出3%收益，每笔都亏。

📌 记忆：预定利率一降再降，根子就是防利差损。客户"锁定高利率"的好，是保险公司"利差损"的压力。

窗口期 / 切换期

监管发文后，旧产品停售、新产品上线的过渡时间段。窗口关闭 = 老产品下架，再买只能买新利率产品。

类比：老款手机清仓倒计时，到点就只剩新款。

📌 记忆：2024.8.31（普通型停）、2024.9.30（分红/万能停）是关键节点。

三类产品区别

普通型（R1）：收益100%写死，最稳。
分红型（R2）：保底+浮动分红。
万能型（R1/R2）：保底+结算利率账户，结算利率每月浮动。

类比：定期存款 / 保底理财+分红 / 余额宝式账户。

📌 记忆：利率越下行，行业越推"分红型"——把收益波动和客户共担。

预定利率研究值

保险行业协会每季度发布，挂钩市场利率（5年期LPR、5年定存、10年国债）。产品利率连续2季度高于研究值25个基点，就要下调。

类比：行业"温度计"。温度降，产品利率跟着降。

📌 记忆：2025年研究值一路降到1.99%，触发了新一轮下调。

限高令 / 630意见函

限高令（2024.3）：分红水平参照万能险结算利率上限，大公司≤3.0%、中小≤3.2%。
630意见函（2025.6.18）：金寿险函〔2025〕374号，防"内卷式"竞争，设六类情形+3.20%指导线。

📌 记忆：监管怕公司"虚高分红利"揽客，逼分红和实际投资能力挂钩。

精算篇 · 卖保险必须懂的"算账逻辑"

现金价值 Cash Value

退保时能从保单里拿回的钱，白纸黑字写进合同、逐年增长。前期低（要扣佣金和费用），往后越来越高，是保单的"净资产"。

类比：还房贷——头几年还的大部分是利息，本金（现金价值）是慢慢攒起来的。

📌 记忆：现金价值 ≠ 已交保费。前几年退保通常"亏"，看计划书"现金价值"列才准。

死差 Mortality Margin

实际身故人数比定价假设少，赔出去的比预期少，差额就是赚的。寿险三大利润来源（三差）之一。

类比：车险一年没出险，保险公司赚的就是"死差"。

📌 记忆：客户越健康、活得越久，死差越正——这是分红的源头之一。

费差 Expense Margin

实际运营费用（佣金、职场、系统）比定价假设省下来的部分。三差之二。

类比：部门年度预算花不完，结余的就是费差。

📌 记忆：险企搞数字化降本 → 费差改善 → 可分配盈余变多 → 分红更有底气。

利差（益） Interest Margin

实际投资收益率比定价假设（预定利率）高出来的部分。三差之首，也是分红的大头。反过来就是"利差损"（见上文）。

类比：以3%借来的钱投出5%，中间2个点就是利差益。

📌 记忆：投资能力是分红的"基本盘"，看险企年报总投资收益率最直观。

三差益 / 三差损 Three Margins

死差、费差、利差三者合计。合计为正＝三差益（形成可分配盈余）；为负＝三差损（吃掉利润）。分红险每年可分的钱，主要就来自这三差。

类比：一家店靠"卖货毛利+省下的房租+理财利息"三条线赚钱，三条线合计才是净利。

📌 记忆：客户问"分红从哪来"——答案就是三差益，主体是利差。

责任准备金 Reserve

保险公司为履行未来赔付/给付，从保费里逐期提存的一笔"专款"，受监管严格监控，不能挪用。

类比：你每月工资里强制存进"履约保证金账户"的钱，专款专用。

📌 记忆：准备金充足率不足会被监管盯上甚至接管，是险企"命门"。

IRR 内部收益率

把历年交的保费和领的钱，折算成"复利年化收益率"。看增额寿、年金真实收益的核心指标，比"单利""翻倍"准得多。

类比：算一笔投资的真实年化回报，而不是被"30年变3倍"这种话术带偏。

📌 记忆：限高后增额寿IRR天花板约2.5%（普通型）、保底约1.75%–2.0%（分红型）。比收益用IRR，别用单利。

生命表 / 死亡率 Mortality Table

统计各年龄段死亡概率的表，是寿险定价的"地基"。预定利率 × 生命表 × 费用率 ≈ 保费。

类比：精算师的"天气预报"——不同年纪出险概率不同，定价跟着变。

📌 记忆：人均寿命越长，养老金/年金定价越贵（要领的钱更多年）。

毛保费 / 净保费 Gross / Net Premium

净保费=纯风险保费（只覆盖赔付）；毛保费=净保费+附加费用（佣金、运营、利润）。你交的是毛保费。

类比：菜品净价（食材）+ 服务费（堂食费）= 你结账的总价。

📌 记忆：交的保费里，一部分"买保障"，一部分"付成本"，别以为全进保障账户。

可分配盈余 / 分红来源 Surplus

分红险每年的盈余，在"可分配盈余"里按不低于70%分给客户（监管硬杠杠）。可分配盈余 = 三差益 + 投资收益等。

类比：公司年终奖池子，监管规定至少70%发给一线（客户），公司留不超过30%。

📌 记忆：分红不是公司"发善心"，是合同约定 + 监管规定（≥70%归客户）。

演示利率是"演算假设"，分红水平是"实际能分多少"。两者都被监管一步步收紧。
📌 当前口径：分红险 演示利率上限 = 3.5%；实际分红水平指导区间约 3.2%（见第④节630意见函）。

4630政策解读（金寿险函〔2025〕374号）

2025年6月18日，金融监管总局人身保险监管司下发《关于分红险分红水平监管意见的函》。业内简称"630政策"。
为什么出这个文件？

低利率下分红险成主推，部分公司为抢份额把分红演示/实际分配做得过激，"虚高分红预期"揽客。监管要防内卷、防利差损：分红必须基于账户真实投资收益和资产负债状况，不能随意抬高。

🔗 监管是"分两步走"的：2025.6（本意见函）压的是"实际分红水平"（3.20%指导线）；到 2026.6.30（业内也简称"630"窗口），进一步把"演示利率上限"由3.9%压到 3.5%以下（详见第③节时间线）。两步合起来，把分红险从"高演示、虚高分红利"拉回理性。所以客户问"630是不是要把分红压到3.5%以下"——准确说是：演示利率上限压到3.5%以下，实际分红水平另有3.20%指导线。
六类情形（出现任一，须充分论证+报资产负债管理委员会审定）
  1. 拟分红率对应的投资收益率，超过该账户过去3年财务/综合投资收益率的较低者；
  2. 分红特别储备为负值，或当期分红实施后将为负值；
  3. 设立不足3年的账户，拟分红水平（客户收益率）超过行业过去3年平均财务收益率 3.20%；
  4. 监管评级1–3级，拟分红水平超过行业过去3年平均财务收益率 3.20%；
  5. 监管评级4–5级，拟分红水平超过产品预定利率；
  6. 产品、精算、投资、财务等部门认为需提交审议的其他情形。
对客户的实质影响

① 分红更"实在"：和保险公司真实投资能力挂钩，不再随意画大饼。
② 老产品实现率仍偏低：早年高演示产品分母大，实现率可能只有50%–90%，这是客观事实，不是公司"不靠谱"。
③ 好公司优势凸显：投资能力强、储备充足的公司，可论证后突破限高，分红更稳；中小公司高分红揽客空间被压缩。

⚠️ 销售红线：绝不能把"演示红利"说成"保证收益"，绝不能承诺"明年分红肯定高"。监管明确：违反者约谈、责令整改、评级扣分。

5为什么现在主流是「保底1.75% + 分红」？

一句话：2024年9月分红型预定利率降到2.0%，产品从"固定收益"转向"保底+浮动"，这是监管鼓励的大方向。

保底1.75% + 分红演示1.225%，整体演示贴近3.0%附近，符合3.5%演示上限与3.2%分红指导线。

2025.6 意见函固化"保底+浮动"结构
630政策进一步明确分红险收益=预定利率保底+浮动红利，逼行业回到"风险共担、收益共享"的本源。
💡 所以现在你看到的主流产品：普通型写死2.5%（或更低）、分红型保底约1.75%–2.0%+浮动分红。客户用"保底部分"锁住底线，用"分红部分"博取上行——这正是利率下行周期里，险企和客户的"公约数"。
