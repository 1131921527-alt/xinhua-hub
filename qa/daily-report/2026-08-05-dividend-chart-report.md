# dividend-2025-interpretation.html 视觉优化报告

## 修改内容

### 1. 累计红利对比由表格改为柱状图
- **文件**：`dividend-2025-interpretation.html`
- **位置**：Part 5「真实案例：宏御世家（分红型）」
- **实现**：
  - 用原生 SVG 绘制分组柱状图，横轴保留年度节点：1、2、3、4、5、10、20、30、40、50、60。
  - 每个节点两根柱：118% 实现率（深蓝 #1D4ED8）、100% 实现率（浅蓝 #93C5FD）。
  - 因金额跨度极大（5,253 元 ～ 9,263,463 元），Y 轴采用**对数刻度**，标注 1万 / 10万 / 100万 / 1000万，确保早期年份仍清晰可见。
  - 鼠标悬停（PC）或点击/触摸（移动端）显示浮层：`第X年度 · 118%实现率 ¥X,XXX,XXX`。
  - 原大表格折叠到 `<details>「📋 查看原始数据（累计红利明细表）」` 中，默认收起，不抢视觉。
  - 图表下方保留说明：`柱状图（对数刻度）用于直观展示118%与100%红利实现率下的累计红利差异，单位：元。`

### 2. 投资能力 / 风险抵御能力标注 2025 年度口径
- 标题改为：
  - `📈 投资能力（2025年度）`
  - `🛡️ 风险抵御能力（2025年度）`
- 两个模块下方分别补充：`数据来源：新华保险公开披露数据（2025年度）`
- 模块引言与底部说明保持口径一致。
