# V4.0 首页信息架构优化报告

> 日期：2026-08-05  
> 范围：xinhua-hub 首页（index.html）+ 资料分类数据（data.json）  
> 提交：`c426a0a`  
> 线上：https://1131921527-alt.github.io/xinhua-hub/

---

## 一、修改目标

让手机端用户打开首页后，最快找到：
1. 智能计划书生成
2. 产品在线测算
3. 销售问答知识库
4. 培训资料

减少无意义展示，避免首页像资料堆积页。

---

## 二、具体修改

### 1. 删除「计划书预览墙」

- 删除 `index.html` 中整个 `.pw-section`（5 张计划书预览图 + 灯箱入口）。
- 保留 `pic-lightbox` 组件本身（通用组件，不排除后续图片查看需求）。

### 2. 调整首页顶部信息优先级

新顺序（从上到下）：

| 顺序 | 模块 | 说明 |
|------|------|------|
| 1 | 头部 + 业务提醒 | 保留 |
| 2 | 🏢 新华Hub 介绍 | 新增：一句话说明网站定位 + 公司介绍入口 |
| 3 | ⚡ 智能计划书快捷生成 | 置顶，不再隐藏在搜索下方 |
| 4 | 🧮 产品在线测算 | 5 款主力产品直达 |
| 5 | 💬 销售问答知识库 | 新增快捷入口卡片 |
| 6 | 🎓 培训中心 | 原有培训专区 |
| 7 | 📈 红利实现率专区 | 知识库入口，置后 |
| 8 | 搜索 + 分类标签 + 动态资料 | 放在静态核心工具之后 |

- 删除了原来的「核心工具」四宫格（与产品测算/培训/销售问答重复）。
- 智能计划书与产品测算定位区分：
  - **智能计划书**：输入自然语言 → 自动生成计划书图片。
  - **产品在线测算**：进入演算器 → 查看详细利益演示/下载计划书。
- 由于两者交互路径不同，保留两个入口，但位置与文案已做清晰区分。

### 3. 「演算表」及下载类资料移到底部

- 调整 `data.json` 分类顺序，将 `excel-tables`（演算表）及 `templates`、`contracts`、`dividend`（分红资料）移到分类列表末尾。
- 首页「全部」视图下，动态内容区不再重复展示：
  - 公司介绍
  - 产品测算
  - 销售问答
  - 培训中心
  这些分类仍可通过顶部标签单独查看，避免首页入口重复。

### 4. 公司介绍位置调整

- 在头部下方新增 `.hub-intro` 静态卡片，说明「新华Hub · 银保资料与工具中心」。
- 点击「了解公司」跳转 `company-intro.html`。
- `data.json` 中「公司介绍」分类仍保留在分类首位，单独标签页可查看。

### 5. 手机端体验优化

- 删除 120px 的 `.home-spacer` 空白占位。
- 核心入口（hub 介绍、智能计划书、产品测算）集中在第一屏；销售问答、培训中心进入第二屏。
- 卡片间距保持 12–16px，与现有设计系统一致。
- 390px 宽度下无横向滚动。
