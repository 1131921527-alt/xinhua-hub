## 一、修改内容

### 1. 盈满鑫导出图表格列宽重分配（`calculator-yingmanxin.html`）

**问题**：年交保费 1000 万时，金额数字位数从 5-6 位涨到 7-9 位（如 `10,000,000` / `31,550,000`），原列宽在 390px 视口下不足以容纳，导致表头「预期身故保险金」「预期年化单利」被压扁、金额数字串格。

**调整方案**（保留手机可读字号，不缩到不可读）：

| 调整项 | 修改前 | 修改后 |
|--------|--------|--------|
| colgroup 列宽 | `6/7/9/8/8/9/11/13/15/14` | `4/4/12/10/12/10/11/13/15/9` |
| 表头 `white-space` | `nowrap`（强制不换行） | `normal`（允许"预期身故保险金"等长词换两行） |
| 表头字号 | 主 14px / 副 13px | 主 13px / 副 12px |
| td padding | `5px 2px` | `4px 1px` |
| fitExportTable 起始字号 | 18px | 16px |
| fitExportTable 下限字号 | 10px | 12px |

**自动适配效果**（fitExportTable 按 1000万/100万/10万 三档实测）：
- ¥100,000 → fontSize=16px（最大最清晰）
- ¥1,000,000 → fontSize=14px（中等）
- ¥10,000,000 → fontSize=12px（仍清晰可读，0 溢出）
