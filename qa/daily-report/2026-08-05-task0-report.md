# xinhua-hub 验收日报 — 2026-08-05（任务0：手机端真实使用体验优化）

## 一、任务目标
按真实业务链路优化手机端体验：打开网站 → 3 次点击内找到入口 → 在线测算 → 查看结果 → 下载图片 → 微信发送客户。
核心要求：
1. 首页手机端清晰，四大入口（产品演算器/培训中心/红利实现率/销售问答）首屏可见。
2. 网页结果页与下载 PNG **标题/表格/字体/边框/数据排列/颜色**一致。
3. 三档金额（10万/100万/1000万）导出图真实可用，10,000,000 / 31,550,000 不得串格、挤压、换行、表头重叠、多余线。
4. 导出图为专业展示方案图，微信缩略图能看清主要数据。
5. 最终验收含手机真实场景：首页/输入/结果/下载/微信查看。

## 二、问题根因
V4.0 新建的 `assets/css/theme.css` 使用裸标签选择器：
```css
th, td { font-size: var(--fs-base); }
```
该规则污染了全站所有表格（包括盈满鑫独立导出模板 `.exp-main` 和 4 款 html2canvas 演算器的 `#planArea`）。
后果：
- 盈满鑫 `fitExportTable` 把 `table.style.fontSize` 降到 9px，但单元格仍被强制 14px，千万级数字换行/串格。
- 4 款 html2canvas 演算器 capturing 态 `font-size:28px` 与固定 table-layout 叠加，1000 万大金额在 800px 宽度下严重挤压。

## 三、修复内容

### 1. `assets/css/theme.css`
将裸标签表格规则改为 `.tbl` 显式启用类，避免污染演算器导出模板。

### 2. `calculator-yingmanxin.html`
- 标题统一为「盈满鑫两全保险 · 分红型 · **理财计划书**」。
- 表头与网页版对齐：「保证身故保险金」「预期身故保险金」「现金价值保证部分」「现金价值保证+红利」。
- 导出模板新增顶部核心指标卡（满期收益/累计收益/年化单利，32px），微信缩略图可读。
- `fitExportTable` 直接把字号写入每个 `th/td` 的 inline-style，并设置 `tbody td { white-space:nowrap }`。

### 3. `calculator-hongan.html` / `calculator-hengxiang.html` / `calculator-hongyu.html` / `calculator-hongyuan.html`
- capturing 态不再隐藏 `.key-metrics`，改为放大显示（标签 18px / 数值 32px）。
- 移除 `table-layout:fixed`；capturing 宽度 800→1000 CSS px，PNG 宽度 1600→2000px。
- 新增 `fitPlanTables()`：按实际数字长度动态降字号（14–28px），`tbody td { white-space:nowrap }` 防止数字换行。
- 增加单元格 padding（th 10px 4px / td 8px 4px），避免视觉拥挤。

### 4. `qa/mobile_scenario_test.py`（新增）
模拟真实手机链路：

- 检测网页/导出区单元格横向溢出、页面级横向滚动。
