## 三、设计系统（theme.css 要点）

```css
:root {
  --primary / --primary-dark / --primary-deep / --primary-light  /* 品牌蓝 */
  --bg / --card-bg / --text / --text-2/3/4 / --border            /* 中性色 */
  --radius-sm/lg/xl  --shadow-sm/md/lg/hover                    /* 圆角阴影 */
  --space-1..10 / --page-x                                     /* 间距 */
  --font-sans / --font-num / --fs-*                             /* 字体渐变 */
  --maxw: 480px                                                 /* 移动端容器 */
}
```
公共类：`.btn/.btn-primary/.card/.section-title/.tag/.grid-2/3/4/.app-container` 等。
**以后改品牌色/圆角/字体/间距，只改 `theme.css` 一处。**
